## 发现的问题

### ISSUE-001 (已修复) (严重)

**标题**: 患者列表页面点击患者卡片后页面导航异常

**严重程度**: 严重 (Critical)

**状态**: ✅ 已修复

**修复内容**:
1. 在患者卡片点击事件中添加 `@click.stop` 阻止事件冒泡
2. 修改代码：`@click="selectPatient(patient)"` → `@click.stop="selectPatient(patient)"`

**修复文件**:
- `/workspace/hemo-mobile-uniapp/src/pages/patient-list/index.vue`

---

### ISSUE-002 (高)

**标题**: Vue Router 版本警告

**严重程度**: 高 (High)

**描述**:
控制台出现 Vue Router 导入警告：
```
[warning] [vue-router]: importing from 'vue-router/dist/vue-router.esm-bundler.js' is deprecated. Use 'vue-router' directly.
```

**证据**:
- 控制台日志多次出现此警告

**修复建议**:
1. 更新 vue-router 版本
2. 或在 vite 配置中排除此警告
3. 检查 @dcloudio/uni-h5 的 vue-router 依赖版本

---

### ISSUE-003 (中)

**标题**: 患者列表页面直接访问时数据为空

**严重程度**: 中 (Medium)

**描述**:
当直接通过 URL 访问患者列表页面（`/#/pages/patient-list/index`）时，页面不显示患者数据。这是因为患者数据是在搜索页面搜索后才加载的。

**证据**:
- 直接访问患者列表页面，页面显示空状态
- 截图: `screenshots/08-patient-list-direct.png`

**修复建议**:
1. 在患者列表页面的 `onMounted` 钩子中检查是否已有患者数据
2. 如果没有数据，自动跳转到搜索页面
3. 或添加一个引导用户搜索的提示

---

### ISSUE-004 (低)

**标题**: 搜索页面时段选择器初始值为空

**严重程度**: 低 (Low)

**描述**:
搜索页面的时段选择器初始显示为空，用户可能不清楚应该选择哪个时段。

**证据**:
- 截图: `screenshots/06-search-page.png`

**修复建议**:
1. 设置时段选择器的默认值为"上午"
2. 或在时段选择器旁边添加提示文字
